Custom Report Fields, Filters, and Summary Statistic Glossaries
Updated 4 months ago
Overview

In this article, you will find a list of Custom Report fields, filters, and 
summary statistics grouped by subject matter. Click on the tabs below to 
view the entire following glossaries:

   - *Custom Report Fields Glossary: *This glossary provides a 
   comprehensive list of all fields that can be added to Custom Reports, as 
   well as what information is expected to populate in those fields.
   - *Custom Report Filters Glossary: *This glossary provides a list of all 
   filters that can be applied to custom reports. This glossary explains how 
   applying each filter will impact the list or orders that will appear in 
   your custom report.
   - *Summary Statistics Glossary: *This glossary provides a list of 
   summary statistics that you can apply to your custom reports, explaining 
   what order data these statistics tabulate.

To learn more about how to set up custom reports, see our guide to creating 
a custom report in Qualia 
<https://knowledge.qualia.com/hc/en-us/articles/25656079904020>. Also, for 
in-depth coverage of how payee label fields work in custom reports, click 
here <https://knowledge.qualia.com/hc/en-us/articles/25656316448404>.

 
Custom Report FieldsCustom Report FiltersSummary StatisticsBasic Info Fields

 
*Accounting Mode* The Accounting Mode field displays the order’s accounting 
mode selected in Basic Info > Type. Other accounting modes can be enabled 
in Settlement Agency settings in Preferences > Accounting. If no other 
accounting modes are enabled, orders will open in Normal Accounting Mode by 
default, and this field will display as “Normal”.
*Order Number* The Order Number field displays the order number. This 
information can be found in the Basic Info section of the order, as well as 
in the top left corner of the order screen. 
*Place of Closing* The Place of Closing field displays the address of the 
place of closing listed in the Basic Info section of the order. The default 
Place of Closing when an order is opened is the address of the Settlement 
Agency.
*Purchase Price* The Purchase Price field displays the value entered in the 
purchase price field in the Basic Info section of the order.
*Representing* The Representing field displays the option selected in the 
“Representing” drop-down menu in the Basic Info section of the order. 
*Settlement Agency* The Settlement Agency field displays the settlement 
agency selected in the Basic Info section of the order.
*Status Summary* The Status Summary field displays the value entered in the 
Status Summary field in the Basic Info section of the order.
*Template Name* The Template Name field displays the order template with 
which the order was set up. You can view the order template in the Basic 
Info section of the order. 
*Transaction Type* The Transaction Type field displays the transaction type 
selected for this order. The transaction type can be viewed and modified in 
the Basic Info section of the order.
*Workflow* The Workflow field displays the workflow selected for the order. 
The current workflow can be viewed and modified in the Basic Info section 
of the order.

 
Property Fields



 
*Address Line 1* The Address Line 1 field displays an order’s property 
address entered in General > Properties.
*Block* The Block field displays the Block entered for an order’s property 
in Properties > Subdivision
*Brief Legal Description* The Brief Legal Description field displays the 
information entered in the “Property Brief Legal Description” field in General 
> Properties.
*City* The City field displays the property city entered in the Properties 
section of the order. If there are multiple properties, the cities of the 
properties will appear in this field separated by commas.
*County* The County field displays the property county entered in the 
Properties section of the order.
*County State* The County State field displays the property county and 
property state entered in the Properties section of the order. The county 
and state will be displayed in the field together, separated by a slash. 
(i.e. Travis / Austin)
*Legal Description* The Legal Description field will display the full text 
entered into the “Property Final Legal Description” field found in Properties 
> Legal Description in an order. 
*Lot* The Lot field displays the value entered in the “lot” field in Properties 
> Subdivision within an order. 
*Parcel ID* The Parcel ID field displays the value entered in the Parcel ID 
field in the Properties section of the order.
*Property Type* The Property Type field displays the option selected in the 
Property Type field in the Properties section of the order.
*Section* The Section field displays the value entered in the Section field 
in Properties > Subdivision.
*State* The State field displays the property state listed in the 
Properties section of the order.
*Subdivision* The Subdivision field displays the value entered in the 
Subdivision field in Properties > Subdivision.
*Zipcode* The Zipcode field displays the property zip code listed in the 
property section of the order.

 
Title Fields

 
*Agent Endorsement Premium* The Agent Endorsement Premium field displays 
the retention portion of an order’s endorsement premiums that are kept by 
the Settlement Agency.
*Agent Policy Premium* The Agent Policy Premium field displays the 
retention portion of an order’s policy premiums that are kept by the 
Settlement Agency.
*Agent Premium* The Agent Premium field displays the combined total of the 
retention of both the policy premiums and endorsement premiums that are 
kept by the Settlement Agency.
*Base Remittance* The Base Remittance Field displays the remittance portion 
of an order’s policy premiums that is paid to the underwriter. It displays 
just the policy remittance, and does not include the endorsement remittance.
*Commitment Effective Date* The Commitment Effective Date displays the date 
entered in the Effective Date field on the right sidebar in the Commitment 
tab of the order.
*Endorsement Premium Remittance* The Endorsement Premium Remittance field 
will display the total amount of endorsement premiums on an order that are 
remitted to the underwriter. 
*Endrosement Premium on Lender Policy* The Endorsement Premium on Lender 
Policy field will display the sum total of all endorsement premiums for 
Lender Policy endorsements.
*Endorsement Premium on Owner Policy* The Endorsement Premium on Owner 
Policy field will display the sum total of all endorsement premiums for 
Owner Policy endorsements.
*Endorsements on Lender Policy* The Endorsements on Lender Policy field 
will display a comma separated list of the names of all endorsements added 
to the Lender Policy on an order.
*Endorsements on Owner Policy* The Endorsements on Owner Policy field will 
display a comma separated list of the names of all endorsements added to 
the Owner Policy on an order.
*Lender Policy ID* The Lender Policy ID field displays the issued Policy ID 
that displays in the Final Policy section of an order after final policies 
have been issued. 
*Lender Policy Issued* The Lender Poilcy Issued field displays the lender 
policy type selected from the Policy Type drop-down menu in the Policy Info 
& Rates section of the order. 
*Lender Prior Policy Age* 

The Lender Prior Policy Age field displays the data entered in the prior 
policy age field in the Policy Info & Rates section of the order. 


 

Note that not all types of lender’s policies have fields to enter a prior 
policy age. You may need to select certain policy and rate types in order 
to get the lender prior policy age field to surface. 
*Lender Prior Policy Liability* 

The Lender Prior Policiy Liability field displays the data entered in the 
prior policy liability field in the Policy Info & Rates section of the 
order.


 

Note that not all types of lender’s policies will have fields to enter a 
prior policy liability. You may need to select certain policy and rate 
types, such as as reissue rate type, in order to get the lender prior 
policy liability field to surface.
*Lender Rate Type* The Lender Rate Type field displays the option selected 
in the Rate Type drop-down menu in the Lender’s Policy tab of the Policy 
Info & Rates section of the order.
*Lender’s Policy Effective Date* The Lender’s Policy Effective Date field 
displays the effective date entered for the Lender’s Final Policy on the 
right side rail of the Final Policy section of the order. 
*Lender’s Policy Issued Date* The Lender’s Policy Issued Date field 
displays the actual date that the Final Lender’s Policy was issued from the 
Final Policy section of the order.
*Lender’s Policy Premium* The Lender’s Policy Premium field displays the 
actual lender’s policy premium that is calculated in the Policy Info & 
Rates section of the order. 
*Owner Policy ID* The Owner Policy ID field displays the issued Policy ID 
that displays in the Final Policy section of an order after final policies 
have been issued. 
*Owner Policy Issued* The Owner Poilcy Issued field displays the owner 
policy type selected from the Policy Type drop-down menu in the Policy Info 
& Rates section of the order. 
*Owner Prior Policy Age* 

The Owner Prior Policy Age field displays the data entered in the prior 
policy age field in the Policy Info & Rates section of the order. 


 

Note that not all types of owner’s policies have fields to enter a prior 
policy age. You may need to select certain policy and rate types in order 
to get the lender prior policy age field to surface. 
*Owner Prior Policy Liability* 

The Owner Prior Policiy Liability field displays the data entered in the 
prior policy liability field in the Policy Info & Rates section of the 
order.


 

Note that not all types of owner’s policies will have fields to enter a 
prior policy liability. You may need to select certain policy and rate 
types, such as as reissue rate type, in order to get the lender prior 
policy liability field to surface.
*Owner Rate Type* The Owner Rate Type field displays the option selected in 
the Rate Type drop-down menu in the Owner’s Policy tab of the Policy Info & 
Rates section of the order.
*Owner’s Policy Effective Date* The Owner’s Policy Effective Date field 
displays the effective date entered for the Owner’s Final Policy on the 
right side rail of the Final Policy section of the order. 
*Owner’s Policy Issued Date* The Owner’s Policy Issued Date field displays 
the actual date that the Final Owner’s Policy was issued from the Final 
Policy section of the order.
*Owner’s Policy Premium* The Owner’s Policy Premium field displays the 
actual owner’s policy premium that is calculated in the Policy Info & Rates 
section of the order. 
*Policy ID* The Policy ID field lists the policy IDs for all issued 
policies on an order. Policy IDs can be found in the right sidebar of the 
Final Policy section of an order. If multiple policies are issued, both 
policy IDs will appear in this field as a comma separated list.
*Policy Issued Date* The Policy Issued Date field displays the actual date 
that final policies were issued on an order. 
*Sales Tax on Title Charges* The Sales Tax on Title Charges field displays 
the amount of the sales tax for title premiums. Note that not all states 
have sales tax for title charges. Orders in certain states are expected to 
return a value of “Not Set” for this field.
*Total Endorsement Premium* The Total Endorsement Premium field displays 
the total endorsement premiums across all title policies. It displays the 
combined dollar value of all owner’s and lender’s policy endorsement 
premiums.
*Total Policy Premium* The Total Policy Premium field displays the total 
combined policy premiums for the owner’s and lender’s policies on an order.
*Total Premium (Before Taxes and Fees)* The Total Premium (Before Taxes and 
Fees) field displays the combined dollar value of all policy and 
endorsement premiums, but does not include taxes and fees, such as sales 
taxes and guaranty fees.
*Total Premium (Including Taxes and Fees)* The Total Premium (Including 
Taxes and Fees) field displays the combined dollar value of all policy and 
endorsement premiums, as well as taxes and fees, such as sales taxes and 
guaranty fees.
*Total Remittance Due* The Total Remittance Due field displays the total 
remittance due to the underwriter, including the underwriter’s portion of 
both policy and endorsement premiums. 
*Underwriter* The Underwriter field displays the name of the underwriter 
selected in the title section of the order.
*Underwriter Fees* The Underwriter Fees field displays the dollar value of 
all underwriter fees generated in the Policy Info & Rates section of the 
order, but does not include policy premiums. For example, the TIEFF Policy 
Fee in Indiana would qualify as an underwriter fee.
*Underwriter Name* The Underwriter Name field displays the name of the 
underwriter selected int he title section of the order.

 
Accounting Fields

 
*Aggregate Disbursement Date* The Aggregate Disbursement Date field 
displays the earliest date that an aggregate payment from an order was 
disbursed in Global Accounting. If aggregate payments are disbursed from 
in-order accounting, but no aggregate payments from the order are disbursed 
in global accounting, this field will show as “Not Set”.
*Aggregate Payee* The Aggregate Payee field lists all aggregate payees from 
aggregate disbursements in an order. If all aggregate payments are pending 
and none have been disbursed in-order, this field will show as “Not Set”. 
If an aggregate payment is voided, the aggregate payee for the voided 
payment will still display in the Aggregate Payee field.
*Balance* The Balance field displays the accounting balance of an order. 
The accounting balance can be found in the in-order accounting ledger.
*Disbursement Account* The Disbursement Account field displays the name of 
the disbursement account selected in the grey sidebar of the accounting 
section of the order.
*Posted Date (Settlement)* The Posted Date (Settlement) field displays the 
date that a disbursement paid to the Settlement Agency on a file is first 
posted. 
*Posted Date (Title)* 

The Posted Date (Title) field displays the date that a disbursement paid to 
an external title company selected in Contacts > Title Companies is first 
posted. 


 

Note that for the Title Companies section to appear in the Contacts section 
of the order, external title agencies need to be toggled on in the branch’s 
Admin settings.
*Posted Date (Underwriter)* The Posted Date (Underwriter) field displays 
the date that a disbursement paid to the underwriter on a file is first 
posted.
*Revenue* The Revenue field displays the dollar amount of revenue that has 
been disbursed in an order. Payments disbursed to the settlement agency on 
a file, and aggregate payments to a payee that has “Is Settlement Agency” 
toggled on in Admin count as revenue.



 
Payee Label Fields

 
*All Other Payee Labels* The All Other Payee Labels field displays the 
total amount of money disbursed to parties that are not the Settlement 
Agency, Underwriter, or External Title Company.
*All Selected Payee Labels* 

The All Selected Payee Labels displays the sum of the totals for the 
following fields that are selected fields for the custom report: All Other 
Payee Labels, All Settlement/Title Payee Labels, All Settlement Agency 
Payee Labels, All Title Company Payee Labels, and All Underwriter Payee 
Labels. 


 

Note that if you select All Settlement/Title Payee Labels, All Settlement 
Agency Payee Labels, and All Title Company Payee Labels for a custom 
report, this will cause the All Selected Payee Labels field to double count 
the money disbursed to the Settlement Agency and Title Company.
*All Settlement/Title Payee Labels* The All Settlement/Title Payee Labels 
field displays the total combined amount of money disbursed to the 
Settlement Agency on an order, and the external Title Company selected in Contacts 
> Title Companies.
*All Settlement Agency Payee Labels* The All Settlement Agency Payee Labels 
field displays the total amount of money disbursed to the Settlement Agency 
on an order that is selected in the Basic Info section of the order.
*All Title Company Payee Labels* The All Title Company Payee Labels field 
displays the total amount of money disbursed to the external Title Company 
selected in Contacts > Title Companies.
*All Underwriter Payee Labels* The All Underwriter Payee Labels field 
displays the total amount of money disbursed to the Underwriter that is 
selected in the Title section of an order.

Other Company Contact Fields

 
*Appraisal Company Address* The Appraisal Company Address field displays 
the address of the appraisal company entered in an order in Contacts > 
Other Contacts. If an order does not have an appraisal company entered in 
Other Contacts, this field will show as “Not Set”
*Appraisal Company Name* The Appraisal Company Name field displays the name 
of the appraisal company entered in an order in Contacts > Other Contacts. 
If an order does not have an appraisal company entered in Other Contacts, 
this field will show as “Not Set”.
*Builder Address* The Builder Address field displays the primary address of 
the builder on an order. To enter a builder on an order, navigate to Contacts 
> Other Contacts and select Builder from the Other Contacts drop-down menu.
*Builder Name* The Builder Name field displays the company name of the 
builder on an order. To enter a builder on an order, navigate to Contacts > 
Other Contacts and select Builder form the Other Contacts drop-down menu.
*Credit Card Co. Address* The Credit Card Co. Address field displays the 
primary address for the Credit Card Company entered in Contacts > Other

Order Status Fields

 
*Status* The Status field displays the order status listed in the Order 
Dashboard section of the order. 
*Pre-open Status* The Pre-open Status field displays the current status of 
orders that were created in a pre-open status. Orders that are currently 
pre-open will display “Pre-open” in this field. Orders that are no longer 
pre-open will display “Opened” in this field. For orders that were never in 
a pre-open status, this field will display as “Not Set”.
*Order Status* The Order Status field displays the status of an order. 
Order status can be viewed and modified in the order dashboard. This field 
will display values such as “Open”, “Closed”, “Cancelled”, “On Hold” or 
“Pre-Open”, depending on the order status selected on the dashboard. 

 
Commission Fields

 
*Salesperson* The Salesperson field displays the name of the settlement 
team member that is in the role that is designated to receive commission. 
You can set an order role to receive commission in Admin > Organization > 
Commissions. 
*Sales Commission* The Sales Commission field displays the total amount of 
commission. This figure is calculated based on the Sales Commission Base 
and the Sales Commission Rate fields. 
*Sales Commission Base* The Sales Commission Base field displays the total 
amount of commissionable disbursements. You can set which types of 
disbursements comprise the commission base in Admin > Organization > 
Commissions. 
*Sales Commission Rate* The Sales Commission Rate field displays the 
commission rate set for the individual user that is in the order role 
receiving commission. You can set an order role receiving commission in Admin 
> Organization > Commissions, and you can set an individual user’s 
commission rate in Admin > Organization > Users.
